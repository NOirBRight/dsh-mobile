# ADR 0005: Operator VPS stable endpoint, tunnel-first policy, and App-only client

- Status: Accepted
- Date: 2026-08-18
- Supersedes in part: ADR 0001 (endpoint modes and default connection policy), ADR 0003 (browser credential clauses)

## Context

Field usage of the ADR 0001 architecture surfaced three recurring failures:

1. **Slow and unstable connections.** The Automatic policy attempts WebRTC direct first. On mainland-China mobile networks (CGNAT, UDP-restricted), direct almost always fails, so every connection pays a multi-second direct timeout before falling back. The fallback itself rides Cloudflare tunnels, which are slow and lossy from these networks; the 25 s ping / 10 s pong-deadline heartbeat then misclassifies the route as stale, producing ping/pong timeouts and reconnect churn. `docs/p2p-without-relay-feasibility.md` already listed these as expected failures of the no-server design.
2. **Credential loss.** Quick Tunnel hostname rotation invalidates origin-scoped browser credentials by design; five-minute pairing offers expire during troubleshooting; and the client deletes an entire Host Profile when a vault read fails, so a transient Android Keystore error is indistinguishable from revocation.
3. **The no-VPS constraint no longer matches the operator.** The operator has an ICP-filed domain, a domestic VPS (about 1 Mbps egress), and an overseas VPS. A user-controlled stable endpoint is cheaper in reliability terms than provider tunnels.

A 2026-08-18 field audit confirmed the failure chain concretely: production Host config still ran `endpointMode: quick` even though the `pair.noirbright.top` Caddy site and the `dsh-gateway-vps-tunnel.service` return path already existed unused; `dsh-web.service` was inactive so the Gateway had no listener (public 502); and the recovery-surface tunnel unit dies with `BindsTo=dsh-web.service`. The measured VPS link (19 ms RTT, ~4.4 Mbps egress) is comfortably sufficient.

Bandwidth check: the tunnel carries only sealed protocol frames (JSON, base64, NaCl overhead). Streaming chat output is on the order of 10 KB/s; 1 Mbps egress (about 100 KB/s effective) is ample, with session-history bursts of a few hundred KB taking a few seconds. It is not sufficient for serving web assets, images, or file transfer, which therefore must not ride the tunnel.

## Decision

1. **The product rule stays Host-owned Public Endpoints; the stable mode is an operator-owned Custom Endpoint.** For this maintainer deployment: the Host keeps an outbound reverse tunnel to the VPS (the existing restricted `ssh -R` systemd unit; frp is an optional later replacement); the VPS terminates TLS (the existing Docker Caddy with automatic certificates on the ICP-filed domain, site `pair.noirbright.top`) and forwards WebSocket traffic to the loopback Host Gateway on its fixed port. Both the Host and the phone only make outbound connections, so no NAT traversal, port forwarding, or UDP reachability is required on either side. This stack is packaged as a self-hostable Docker Compose recipe (Caddy auto-TLS + frps, with a Host-side frpc companion) so any operator can run their own equivalent.
2. **The released product keeps two endpoint modes and no project-operated shared relay.** Quick Tunnel remains the zero-configuration default for Hosts whose operator provisions nothing (each user rides their own Cloudflare tunnel at zero project cost); a self-hosted Custom Endpoint is the recommended stable mode. The maintainer's VPSes are private Custom Endpoint instances, never product defaults or a shared multi-tenant relay: operating public relay infrastructure is rejected for load, cost, and compliance reasons. The maintainer may run the self-host stack on both his domestic and overseas VPS and share access with friends and colleagues at small scale (within the measured ~50 concurrent-active budget per instance). The Quick Tunnel provider becomes pluggable (cloudflared default; any command yielding an HTTPS+WSS URL, enabling domestic providers by configuration). For the maintainer's own deployment, Quick Tunnel is development-only.
3. **One Public Endpoint serves all of a Host's paired devices.** Each pairing mints an independent 128-bit room with a room-scoped device token; the Gateway authorizes all live rooms concurrently (abuse ceiling `MAX_LIVE_DEVICES = 256`). Advertising multiple concurrent endpoints stays out of scope; devices holding a stale endpoint URL use Endpoint Refresh.
4. **Automatic policy becomes tunnel-first.** The client connects through the configured endpoint tunnel immediately. A WebRTC direct attempt may run in parallel with a short grace window (for the same-LAN case, where direct saves endpoint bandwidth); if direct does not win within the window, the session stays on the tunnel with no mid-session migration. Direct Only and Tunnel Only remain explicit options. The active route stays visible in the UI.
5. **The browser Product Client is removed.** The Host Gateway stops serving the browser shell; browser QR offers, `BrowserCredentialVault`, and the `capabilities.browser` flag are retired. The APK is the only Product Client. Maintainer personal recovery surfaces remain separate operator infrastructure.
6. **End-to-end trust is unchanged.** The NaCl handshake anchored on the QR Host public key still runs over every route; the endpoint is an untrusted pipe that sees only connection metadata and sealed frame sizes. Raw DSH :3080 is never exposed; the Gateway remains loopback-only behind the reverse tunnel.
7. **The APK ships the complete UI skeleton and the tunnel carries protocol frames only.** Shell, fonts, styles, and the Mobile Layout are packaged in every APK release. Host official plugin manifests/bundles are Host-versioned content and are therefore cached on-device by content hash after first connect rather than baked into the APK: cold start renders immediately from cache, revalidates revisions in the background, and re-downloads only changed bundles. Steady-state launches transfer zero assets. Reconnection rehydrates the session over the existing shell instead of a full page reload.
8. **Credential robustness.** A transient vault read error must not delete the Host Profile; only a definitive "secret missing" result may invalidate it. A stable hostname removes routine Endpoint Refresh; the flow is kept for deliberate endpoint changes. Device tokens remain valid until Host-side revocation.
9. **Heartbeat parameters are re-validated** against the low-latency domestic link and made tolerant enough that provider jitter alone cannot mark a route stale.
10. **The overseas VPS hosts a second self-host-stack instance** (friends-and-colleagues use, and a candidate secondary endpoint later). Multi-endpoint Host Profiles remain out of scope: each Host Profile still knows one endpoint URL at a time.

## Consequences

- Connection setup no longer waits on a doomed direct attempt; steady-state traffic rides a user-controlled, low-latency, fixed-hostname path.
- Hostname rotation disappears from normal operation, eliminating the main credential-loss source; the vault-error fix removes the second one.
- The released product keeps zero project-operated infrastructure: default users ride their own Quick Tunnels; stability-seeking operators self-host the documented Custom Endpoint stack. The maintainer's stability depends on his own VPS, an accepted trade already covered by the Custom Endpoint contract.
- Cold start becomes render-from-cache: after first connect, launches show the UI immediately and only session frames cross the tunnel, which also keeps the 1 Mbps-class egress budget comfortable.
- Browser-shell serving, browser pairing, and origin-scoped credential handling are deleted, shrinking the Gateway surface and the test matrix.
- The 1 Mbps egress budget becomes a protocol design constraint: no asset serving, size-bounded transfers, content-hash caching for plugin bundles.
- ADR 0001 remains authoritative for Host identity, endpoint/identity independence, host-owned endpoint modes, Gateway boundedness, and Endpoint Refresh; its direct-first Automatic policy and browser clauses are superseded. ADR 0003 remains authoritative for native vault storage; its browser clauses are moot.
